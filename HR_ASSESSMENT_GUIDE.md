# HR Assessment Configuration Guide

## 🎯 Overview

The NextRound platform now supports **fully customizable question counts** per aptitude category, giving you complete control over your assessment strategy.

## 🚀 Quick Start

### Default Configuration
- **Total Questions**: 20 MCQs (≈30 minutes)
- **Distribution**: 5 questions per category
- **Categories**: Quantitative Aptitude, Logical Reasoning, Verbal Ability, Data Interpretation
- **Passing Score**: 80%

### Built-in Presets

| Preset | Total Questions | Time | Use Case |
|--------|----------------|------|----------|
| **Quick (8Q)** | 2 per category | ≈12 min | Initial screening, high-volume roles |
| **Standard (20Q)** | 5 per category | ≈30 min | Most technical positions |
| **Comprehensive (40Q)** | 10 per category | ≈60 min | Senior roles, critical positions |

## 🎛️ Customizing Your Assessment

### 1. Per-Category Configuration
- **Adjust individual counts**: Use +/- buttons or type directly
- **Category focus**: Emphasize specific skills (e.g., 10 Quantitative, 3 Verbal)
- **Smart limits**: 0-50 questions per category maximum

### 2. Quick Actions
- **Reset Equal**: Redistribute total equally across all 4 categories
- **Preset Templates**: One-click common configurations
- **Real-time Updates**: See total count and time estimates instantly

### 3. Advanced Options
- **Passing Score**: 50%-95% threshold (recommended: 75-85%)
- **Time Estimation**: ~1.5 minutes per question average
- **Validation**: System prevents invalid configurations

## 📊 Category Breakdown

### Quantitative Aptitude 🧮
- **Skills**: Mathematical reasoning, numerical analysis
- **Recommended**: 4-8 questions for technical roles
- **Examples**: Percentages, ratios, data sufficiency

### Logical Reasoning 🧠  
- **Skills**: Critical thinking, pattern recognition
- **Recommended**: 4-6 questions for all roles
- **Examples**: Syllogisms, assumptions, conclusions

### Verbal Ability 📚
- **Skills**: Communication, comprehension
- **Recommended**: 3-5 questions for client-facing roles
- **Examples**: Reading comprehension, grammar, vocabulary

### Data Interpretation 📈
- **Skills**: Chart analysis, trend identification  
- **Recommended**: 3-6 questions for analytical roles
- **Examples**: Graphs, tables, statistical analysis

## 🚨 Troubleshooting

### Common Issues

**"Not enough questions in a category"**
- Solution: Reduce count for that category or contact support for more questions

**"Candidates finishing too quickly"**  
- Solution: Increase total questions or adjust difficulty weighting

**"Too many candidates failing"**
- Solution: Lower passing score or reduce question count

**"Assessment taking too long"**
- Solution: Use Quick preset or reduce per-category counts

### Support Resources
- **In-app help**: Click the question mark icon
- **Live chat**: Available during business hours  
- **Documentation**: Complete guides in Help Center
- **Training videos**: Assessment setup tutorials
