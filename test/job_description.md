# Senior Full Stack Software Engineer (AI Platforms & Systems)

## Company Overview
TechPlatform Solutions is a high-growth cloud intelligence enterprise delivering AI-orchestrated developer infrastructure and edge analytics worldwide.

## Role Overview
We are looking for a Senior Full Stack Software Engineer with deep expertise in modern web technologies and distributed backend services. You will design, build, and maintain our high-throughput developer platforms, integrate LLM/agentic workflows, and optimize data persistence layers.

## Key Responsibilities
- Architect, build, and deploy robust, high-performance web applications and distributed backend microservices.
- Design responsive, intuitive user interfaces using React, Next.js, TypeScript, and modern component systems.
- Build high-concurrency asynchronous backend APIs and services using Python (FastAPI/Django) and Node.js.
- Model, optimize, and maintain complex relational databases in PostgreSQL, including indexing, query optimization, and schema migrations.
- Build resilient asynchronous task workflows, distributed caching, and messaging queues using Redis and BullMQ.
- Lead CI/CD pipeline automation, containerization using Docker and Kubernetes, and cloud infrastructure deployment on AWS.
- Implement security best practices, OAuth2/JWT authentication, and role-based access control (RBAC).
- Conduct rigorous code reviews, mentor engineers, and uphold system architecture standards.

## Qualifications & Technical Requirements
- 5+ years of professional software engineering experience building scalable full-stack applications.
- Strong proficiency in Python (FastAPI, Pydantic, AsyncIO) and TypeScript/JavaScript.
- Hands-on expertise with React, Next.js, HTML5, and modern CSS/TailwindCSS.
- Deep expertise in relational database architecture with PostgreSQL and query tuning.
- Experience with distributed queues and caching (Redis, BullMQ, Celery).
- Solid grasp of containerization and orchestration (Docker, Kubernetes) and AWS cloud services (S3, ECS, Lambda).
- Experience integrating AI/LLM models, prompt pipelines, or vector embeddings is a strong plus.
- Bachelor's degree in Computer Science, Software Engineering, or equivalent practical experience.
